# 📄 Currículo Web - Gabriel Eduardo

Este repositório contém uma página web simples e estruturada desenvolvida para apresentar meu currículo profissional como **Desenvolvedor de Software**.

O projeto foi construído como parte de uma atividade prática no curso de **Desenvolvimento de Sistemas do SENAI**, focando no uso de **HTML5** semântico e **CSS3** para estilização limpa e responsiva, pronta para consumo por recrutadores e leitores de telas/ATS.

🌐 **Acesse a versão online:** [https://github.com/BillyNelson07/curriculo-gabriel-eduardo/deployments/github-pages]

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica (`<header>`, `<section>`, tags de acessibilidade).
- **CSS3:** Estilização responsiva, flexbox e organização visual.
- **GitHub Pages:** Hospedagem estática direta do repositório.

---

## 📌 Conteúdo da Página

- **Informações de Contato:** Links diretos para LinkedIn, GitHub e canais de contato.
- **Resumo Profissional:** Apresentação objetiva do perfil técnico.
- **Habilidades Técnicas:** Tags visuais destacando stacks como Node.js, Java, SQL, Git e conceitos como POO e SOLID.
- **Projetos Práticos:** Detalhamento de projetos do portfólio (ex: _MentorIA_).
- **Formação Acadêmica:** Histórico de cursos no SENAI e Unicesumar.
- **Idiomas:** Nível de proficiência e aplicação técnica.
